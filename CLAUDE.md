# CLAUDE.md

**`AGENTS.md` in this directory is the single project authority. Read it before
any meaningful work here.** It carries the purpose, stack, commands, Map,
conventions, and the CSS-hostility rules that are easy to get wrong.

This file is deliberately a pointer, not a second copy. Parallel
`AGENTS.md` / `CLAUDE.md` files drifted badly across this workspace — by
2026-08-20 several projects had a rich `AGENTS.md` and a `CLAUDE.md` stub, so
Claude was working from a fraction of the context Codex had. One authority per
project is the fix; duplicating it here would recreate the problem.

Also read `DECISIONS.md`, and the local untracked `STATUS.md` (create it if it
is missing).
