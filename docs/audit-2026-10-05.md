## Fixed

| Finding | Change and evidence |
| --- | --- |
| App UI receives generic replacement | Exclude ElevenLabs and GDBrowser, plus the Krea, Runway, Suno and Descript app families. Routed browser pages verify controls survive while DNR stays active. Domain-boundary lookalikes remain in scope. |
| Encoded image bytes look like ad-network names | Use parsed HTTP(S) hostnames at dot/hyphen boundaries. Reject data/blob payloads, paths, query strings, fragments and usernames as network identity. Inspect `srcdoc` resource attributes in an inert template. |
| Ad-sized controls and editors disappear | Protect native buttons, ARIA controls/toolbars, empty and plaintext-only `contenteditable` values, and wrappers lacking stronger ad evidence. Real ad units with close/CTA buttons remain replaceable. |
| Later custom elements evade safety checks | Remove the first-200-descendants cutoff; a late opaque widget can contain an invisible closed shadow root just like an early one. |
| Late cards repeat their neighbour's note | Choose a new note around the nearest existing neighbours and preserve established assignments. Reproduced with controlled scan timing. |
| Valid reports receive “not filed through a form” | Accept GitHub's trimmed form-only titles. Both current reports arrived as `[false-positive]`, without the trailing space required by the old parser. |
| Blank captures look clean | Share page-health checks between live evals and false-positive diagnosis, measure rendered text rather than hidden loading text, and return failure for invalid diagnoses. |

Fifteen scanner/rotation cases fail against the original modules and pass with
the fixes. The final focused suite contains 21 cases, including real-ad positive
controls and a hidden-loading-text case. It runs in CI.

## Safe-list choices

The additions follow the existing product-interface tier: turn off generic
visual replacement, retain network blocking. They do not grant the complete
network exemption reserved for sensitive pages.

The reported ElevenLabs voice library and GDBrowser profile are interactive
tools. The additional creative suites have the same risk: their own media
previews and editing controls are the content the user came to use. Official
product references: [Krea](https://www.krea.ai/),
[Runway](https://runway.com/), [Suno](https://suno.com/),
[Descript](https://www.descript.com/). Both `runwayml.com` and its current
`runway.com` domain are covered, including subdomains.

## Remaining limits and useful follow-ups

- The original GDBrowser replacement did not recur. Its renderer does produce
  PNG data URLs, and that general failure mode is now reproduced and fixed,
  but it is not proven to be the original report's cause. Its host is protected.
- ElevenLabs initially returned a blank app, then redirected to sign-in. No
  authenticated voice-library session was inspected. The reported host's
  protection is covered by deterministic and routed browser tests.
- Live “pass” means a usable page and no authored policy mismatch; it does not
  establish that every card is correct or every ad is gone. Forbes still has
  11 visible suspect signals. Those require element-level review before any
  selector is widened. Daily Mail and MSN remain unverified in this environment.
- A first-party creative identified only by an ad-like URL path now needs
  another signal. Accept this conservative under-replacement rather than
  classifying ordinary image filenames as network evidence.
- With two notes, inserting between two different fixed neighbours cannot
  avoid matching both. Later page-layout changes can also change reading order;
  the extension deliberately does not rewrite notes as the user reads them.
- The pure future risk-tier classifier is still not the runtime gate. This
  audit changed the actual DOM gate and tested it, rather than extending only
  the unused classifier's protected-domain list.
- No Chrome Web Store release was built or submitted by this audit.
